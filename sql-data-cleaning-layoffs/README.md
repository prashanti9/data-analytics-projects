# SQL Data Cleaning — Layoffs Dataset

**Tool:** SQL | **Type:** Professional training course project

## Description
Practiced a full data cleaning workflow in SQL on a layoffs dataset, covering the standard steps of preparing raw data for analysis: removing duplicates, standardizing text values, and resolving null/blank values.

## Workflow
1. `01-remove-duplicates.sql` — creates a staging table and removes duplicate records
2. `02-standardize-data.sql` — trims whitespace and standardizes text values (e.g., company names)
3. `03-handle-nulls-and-blanks.sql` — identifies and resolves null/blank values using self-joins

## Skills Demonstrated
Staging tables, `TRIM`, self-joins for null resolution, data standardization

## Files
- `01-remove-duplicates.sql`
- `02-standardize-data.sql`
- `03-handle-nulls-and-blanks.sql`
- `data/layoffs-raw-data.csv` — raw source dataset
