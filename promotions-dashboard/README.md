# Promotions Dashboard

**Tool:** Power BI | **Type:** Professional training course project

## Description
Built a multi-page dashboard analyzing the impact of promotions on retail revenue, using Walmart order data. The report compares revenue with and without promotions and breaks performance down by store, month, and product.

## Features
- Page: *Total Revenues* — KPI cards for revenue with/without promotions
- Page: *Revenue by Month & Store* — 100% stacked column chart by store location and month
- Page: *Revenue with Promotions* — line chart of revenue trends over time
- Slicers for promotion type and promotion usage

## Skills Demonstrated
DAX measures comparing scenarios (with/without promotion), multi-page report design, trend and comparison visuals, slicers/filters
